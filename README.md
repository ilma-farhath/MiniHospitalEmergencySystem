# Mini Hospital Emergency Management System

## Student

Ilma Farhath

## Description

This project is a console-based Java application developed for the CIT300 Data Structures and Algorithms module.

The system manages:

- Patient Records using Binary Search Tree (BST)
- Emergency Patient Queue using Queue
- Treatment History using Stack
- Patient Visit History using Singly Linked List

## Data Structures Used

### Binary Search Tree (BST)

Used to store patient records.

Operations:
- Insert
- Search
- Delete
- In-order Traversal

### Queue

Used to manage emergency patients.

Operations:
- Enqueue
- Dequeue
- Display Queue

### Stack

Used to store completed treatments.

Operations:
- Push
- Pop
- Display Stack

### Singly Linked List

Used to manage visit history.

Operations:
- Add Visit
- Search Visit
- Remove Visit
- Display Visits
